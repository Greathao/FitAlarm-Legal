# FitAlarm Legal Site

FitAlarm 的中英文隐私政策、服务条款和支持页面。该目录设计为独立 GitHub Pages 项目，不依赖构建工具。

## 页面

- `index.html`：入口页
- `privacy.html`：隐私政策
- `terms.html`：服务条款
- `support.html`：支持与常见问题

## 发布前

在 `site.js` 中替换以下两项：

- `SUPPORT_EMAIL`：真实可用的支持邮箱
- `GITHUB_ISSUES_URL`：已配置为本仓库的 Issues 地址

随后在 GitHub 仓库 Settings → Pages 中选择从 `main` 分支根目录发布。
